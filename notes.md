* Human (O) response options:
    * If Human plays the Center: Computer should play the opposite/diagonal corner on turn two. This forces the human to block, leading to a guaranteed draw if both players play perfectly.
    * If Human plays another Corner: Computer should play the center or another non-adjacent corner to set up a double-attack (fork) trap.
    * If Human plays an Edge: Computer should take the center, securing a position where a human error will allow the computer to create an unstoppable winning
